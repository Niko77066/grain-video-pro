# A/C 风格包形态实验暴露的待办（2026-07-27）

来源：`whiteboard-generalist`（手写兜底包）vs 现场合成冻结包的两臂对照实验。
下列五条**与 A/C 之争无关**——不管风格包最后长什么样，它们都得修。按优先级排。

实验记录在 scratchpad（`exp-ac/PREREG.md` / `RESULTS.md`），未入库。

## P0 · G2 评审协议未规定配对还是单臂，而两者能翻转结论

**证据**：同一批 hero frame，两种评审模式给出相反胜负。

| | 配对路 | 单臂路 |
|---|---|---|
| T1 | A 15 : C 34（C 大胜） | A 23 : C 21（A 微胜） |
| T2 | A 28 : C 32 | A 28 : C 29 |

配对分减单臂分：A-T1 −8、C-T1 +13、A-T2 0、C-T2 +3。T1 的配对评委把两臂朝相反方向拉开 21 分，T2 的几乎没拉开（A-T2 四维一分不差）。

**问题**：`tools/judge/` 现在没说清哪种模式、什么时候用哪种。评审结论因此取决于当时随手选了哪种，这让 `_iteration.md` 的棘轮和风格包准入考片制都失去可比性。

**要做**：把评审模式写进 `tools/judge/README.md` 协议，至少定清——

- 绝对判断（够不够出厂、Golden 下限）必须走**单臂**：有对照物时分数会被对手质量污染；
- 相对判断（新旧版本、A/B 方案）必须走**配对**：跨会话的绝对分不可比；
- 两路都跑时的合并规则，以及分歧多大算"结论不稳、不得声称胜负"。

## P1 · `style-contract@1` 表达不了跨镜头与时间维度的约束

**证据**：四份风格包各自最核心的缝合装置，**全部只能落进 `inviolable` 的自然语言**——

| 包 | 全片最要紧的那道门 | 现状 |
|---|---|---|
| C-T1 | 每镜必须有剖面带；卡钳常驻 | 自然语言 |
| C-T2 | 双版入场时间差 ≤2 帧；两章等长（差 ≤3.0s） | 自然语言 |
| pixel-chronicle | MG 段与实拍段严格交替 | 部分可码判 |
| case-file | 三声部不可删 | ✅ 已可执法 |

能翻译成"谁占多少时长、有几个镜头、有几个 `<video>`"的门都保住了；凡是"某元素在时间上怎么变化""同一件事在不同镜头间是否一致"的门，一条都表达不了。

**讽刺之处**：风格包存在的理由就是跨镜头一致性，而合同格式恰恰表达不了跨镜头一致性。

**要做**（按性价比排）：

1. `plan.chapter_delta_s_max` 之类的**区间算术门**——章节/段落时长相减，是纯算术，最容易补；
2. **跨镜头元素在场性**：某个声明的常驻 overlay 是否出现在每一镜（IR 层可查）；
3. **跨镜头主色漂移**：逐镜取帧算主色直方图、两两距离的方差，补进 `tools/measure-render.py`（复用现有 `gray_frames` 抽帧路径，约三十行）。这一条同时把"缝合层成立了没有"第一次变成可测量的。

## P2 · `whiteboard-generalist` 不含色板 hex，下游每次自行发明

**证据**：两个选题的 hero-spec 作者都报告"风格包没给色板 hex，我自己定了一套"。后果在评委那里两题都被抓到——

- T1："橙在第 2 张占半屏，前后彻底消失，它没有语义"
- T2："f1/f2 建立的蓝＝冷链，到结论镜同时是管路、柜体、还有货架里的商品方块，颜色从论证工具退化成装饰色"

**根因**：那份色彩约定只活在单次会话的上下文里，不在任何文件中。所以它保不住跨镜头，更保不住跨会话。

**要做**：给兜底包补一套**语义绑定**的最小色板（不是配色表，是"这个颜色只准表示什么"），以及"选定后写入 `meta.style_notes`、全片只读"的纪律。兜底包的定位是对选题最大限度开放，所以色板本身可以由 agent 现场选，但**必须落文件、必须绑语义、选完即冻结**。

## P3 · `whiteboard-generalist` 不自包含

`styles/whiteboard-generalist/playbook.md` §8 指向 `produce/SKILL.md §1.3` 的开拍提问模板。把包切出来单独用（子 agent 任务卡、评委证据包）就缺一块——本轮 A 臂两个编剧都撞上了，只能按 playbook 点名的决策项自行反推。

**要做**：要么把提问模板抄进包内，要么改成不依赖外部章节号的自包含表述。
