# Meme Ledger 生产证据

这是已验证横版样片的**可追溯执行证据**，供后续 agent 复现、质检和审计使用。文件内容由本项目用户明确授权进入仓库；相应范围与限制见 `rights/`。

| 文件 | 用途 | 校验与使用边界 |
|---|---|---|
| `video/realestate-agency-landscape-banfo-no-punct.mp4` | 已验证的 16:9 最终成片样例 | 用于核对版式、横版构图、无特效、静态无句末标点字幕和整体声音关系；不是新内容的素材库 |
| `audio/banfo-source.m4a` | 已授权的声音复刻参考 | 只可用于本风格包项目级授权的 MiniMax 声音复刻/核验；不得转用于其他项目、声音或身份 |
| `audio/roundabout-authorized.webm` | 固定授权纯器乐 BGM | 以循环方式垫在旁白下；不得替换为同名但不同录音版本 |

`manifest.json` 固定了每个二进制文件的 SHA-256、格式、时长和授权引用。执行 agent 在使用前应重新计算哈希并逐项比对；不一致即停止使用并要求项目负责人重新登记。

运行时只从项目密钥管理/环境变量读取 MiniMax 音色 ID 和 API 凭据。**不得**把这些凭据、浏览器 Cookie、下载登录态或未登记的参考音频提交到仓库。
