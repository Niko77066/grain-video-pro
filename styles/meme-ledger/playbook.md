# 风格包 · Meme Ledger（梗账本）

> 可投产的固定横版配方，质量状态仍为候选：固定栏目包装已经跑通，但需要更多独立样片完成 Golden 认证。它不模仿任何具体创作者；口播讲清商业机制，合作频道的真实动作只承担平行隐喻。

## 0. 固定配方

- 画幅：固定 `16:9` 横版。需要竖屏时新建适配预设，不能把横版静默裁切。
- 视频：只用项目已登记合作授权的 [UnusualVideos](https://www.youtube.com/@UnusualVideos) 频道选段。每镜记录原 URL、video ID、入/出点、用途与 `license_ref`。
- 声音：MiniMax `speech-2.8-hd`，运行时从 `MINIMAX_MEME_LEDGER_VOICE_ID` 读取项目已授权的固定声音档；授权引用写入 `audio.voiceover.authorization_ref`。共享包绝不保存真人身份、真实音色 ID 或参考音频。
- BGM：固定 `track_id: meme-ledger-main` 的项目授权纯器乐循环版本；`audio.music.license_ref` 是交付前提，`selection_seed` 固定留痕以便重跑。
- 装配：HyperFrames 只做原素材时间窗、静态比例适配、硬切、静态字幕与混音。无转场、动效、滤镜、调色、颗粒、缩放、平移或变速。
- 字幕：固定位置、白色粗体和黑色描边/阴影；每屏 1–2 行，**句末不加 `。！？… .!?`**。

## 1. 适用边界

- 适用：有反差事实或连续机制链的商业、互联网、消费与案例解说；项目已具备合作频道素材授权。
- 不适用：事故灾难、个体受害者、医疗/法律建议、金融强监管建议、仍在核查中的指控、需要主播出镜的片。
- 频道视频不是事实证据。所有事实主张仍要在 `research.md` 回链；画面只做动作反差、预期落空、升级或呼吸。

## 2. 开拍提问

1. 反常识表象是什么？用一句话说出“谁在什么约束下，以什么机制得到什么反常结果”。
2. 谁付钱、谁获利、谁承担风险或退出？至少列出三次可回链的转移。
3. 哪三条事实已核验？它们的原始来源是什么？
4. 哪个日常物件可以成为全文反复回收的母比喻？
5. 项目是否已经登记频道、声音和 BGM 的授权引用？任何一项缺失都不能进入 deliver。

## 3. 文案引擎：结构移植而非口癖模仿

结构移植项目先读 `references/golden-mother-index.json`、`references/golden-mother-cards.md`、`references/golden-source-library.json`、`references/human-speech-engine.md` 和 `references/f-of-x-transplant-design.md`；选定 G08 另读 `references/g08-surface-prose-profile.md`。

1. 先按叙事发动机锁定一篇主母稿，并记录两个被排除候选。沿付款/交付/沉没成本生命周期拆账才可用《奶茶加盟》；没有连续收费链的服务机制题转去更匹配的发动机，不要因为角色多就硬套。
2. 为每段标记任务、相对篇幅、情绪位置、问题密度、母比喻任务和事实槽位，再建“母稿段落作用 / 原段摘要 / 新稿对应段 / 保留结构项”对照。
3. 每个相邻段必须说明 `具体裂缝 → 下一段必须出现的对象或动作`。只能回答“逻辑上也该讲”即断链，退回映射。
4. 母比喻至少回收四次，每次解释新的关系。每个笑点必须引出事实推断、转场裂缝或情绪落点，不能只负责逗笑。
5. 用户要求 75–150 秒短版时标记为 **compressed adaptation**：记录保留的一条连续升级链、删掉的段落任务和理由；不得假称完整母稿移植。
6. 最后才按已冻结口播选视频；不得为了迁就现成梗片改变因果推进。

文案进入 TTS 前，必须通过 `human-speech-engine.md` 的六问复核、Golden 评分（≥21/25 且单项不低于 3）和 Anti-Smooth Gate。不得复用对标稿的独特句子、固定口令、真人声线或可识别口癖。

## 4. 视觉与剪辑

- 全片底画面为授权频道真实运动选段，时长占比 100%，至少 6 段；正常段 0.6–2.5 秒，动作完成可放宽到 4 秒。
- 切点同时满足以下三者至少两项：口播句读/重音、源视频动作落点、BGM 强拍。
- 只允许硬切。每 10–14 秒可保留一个完整动作作为呼吸，但不得用冻结帧或文字卡补时长。
- 黑边只用于横版源比例适配；不放标题、角标、贴纸、进度条、结论卡或证据卡。
- 不得把频道画面和字幕组合成“事实现场”的错觉。

## 5. 音频

- 旁白 single-pass 生成；改一个字即重跑整轨与强制对齐。独立回转写与冻结剧本一致率至少 95%。
- 固定 BGM 只使用项目授权的纯器乐循环片段；旁白始终第一，BGM 低约 18–22 LU，整体目标 -14 LUFS、true peak ≤ -1.5 dBTP。
- 声音与音乐的授权文件留在项目 `rights/`，只把引用路径写进 Film IR；不把音频、音色 ID 或授权材料本体提交到共享仓库。

## 6. 反模式（一票否决）

- 使用非指定频道的底画面，或任一频道选段缺 URL、video ID、入出点或授权引用；
- 把频道视频当证据，或用无关字幕伪造事实现场；
- 一句一梗的机械乱切、静帧补时长、连续文字/图形卡；
- 任何视觉效果、卡片、贴纸、角标、动效字幕或深色字幕底框；
- 字幕句末标点、未登记授权的声音/BGM、BGM 盖住旁白；
- 使用真实受害者、灾难、疾病或普通人的窘境当 punchline；
- 模仿在世创作者的个人声音、口癖或独特句子。

## 7. 出厂与迭代

1. `kuleshov-ir validate` 的 `style.contract.plan`、`style.contract.audio`、`style.contract.compose` 和 `style.contract.render` 零 error；
2. 抽帧确认只有授权视频和静态字幕，无视觉效果；
3. 资产账本证明频道、声音和固定 BGM 的授权引用；
4. 改动本包后，实际复跑 `test-shots.json` 的三个考题，再按 `styles/_iteration.md` 走配对评审；
5. 多条独立样片通过 Golden 认证前，`capability.json` 保持 `candidate`，但固定生产配方可正常使用。
