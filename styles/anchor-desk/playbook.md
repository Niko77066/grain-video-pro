# 风格包 · Anchor Desk（主播台 · 新闻播报）

> 机械硬门在本目录 `contract.json`（护栏面持有，本文不复述阈值）；本文管创作方法，审美要求交 Judge。
> **一句话定位**：学电视新闻的**形式**（正襟主播、蓝金演播室、数据大屏、来源脚注、恒定角标），不学它的**腔调**——行文仍走 But/Therefore 与事实回链。

## 0. 档案

- 状态：**候选（单片标定）**。从 `projects/china-h1-2026-econ`（《经济半年报》4.7% 背后的两组数字，82s，16:9）蒸馏。
- 拉片对象：CCTV 新闻联播的**形式语法**（用户口述诉求，非逐帧拉片）；不是从某条具体片子拆的，所以合同阈值全部标 `[单片标定]`，待第二、三片回填。
- 适用片型：`anchor_news_recap`（数字人主播版资讯速览）、数据发布解读、政策/财报/统计口径类播报。
- 唯一硬不兼容：**用数字人冒充任何真实人物**（真实主播、官员、当事人）——虚构栏目人设可以，冒名不行；也不许出现任何真实电视台的台标、栏目名、主播姓名。这是三包共同规则「真人只允许符号化角色」在本包的具体化。
- 考片记录：单片出厂，G2 成片门第 3 轮 **4.1 分 / 反模式空数组** pass（`judge-report-final-r3.json`）。未过盲评对照，**不算转正**。

## 1. 链路配方（硬）

**四声部混排，一个都不能少**：

| 声部 | provider | 在本包里的固定叙事角色 | 份额（实证片） |
|---|---|---|---|
| **主播** | `avatar` | 主持 / 设问 / 结论——片子的"人"，负责起承转合的关节 | 19.6% |
| **实拍物证** | `footage` | 给每个数字一个物理世界的对应物（港口之于外贸、超市之于物价） | 34.7% |
| **数据屏** | `hyperframes` | 信息主轨：数据面板、转折字卡、结论卡、字幕层 | 33.2% |
| **静帧特写** | `image_motion` | 数字的递进与聚焦（全景 → 特写 + 大数字） | 12.6% |

- 声部声明写 `shots[].source.params.voice ∈ {anchor, broll, broll_still, data_screen}`（storyboard 必填，合同按此计数）。
- **数字人不是全片贴片**：主播镜只在开场 / 转折设问 / 收尾这三个关节出现，中间由实拍与数据屏承担。整片从头到尾单人对镜头是反模式。
- 主播形象锚点必须**按目标画幅构图**生成（16:9 栏目就出 16:9 半身像），并与 TTS 音色档**固定配对**，跨片跨期不换——人设是栏目级资产。
- 本包**不用** AI 生成 b-roll（seedance / collage）。新闻质感来自真实素材，生成的氛围镜会破坏它。

## 2. 视觉系统

### 色板（CSS tokens）

```
--navy-0:#0A1E3C  --navy-1:#123A6B  --navy-2:#061428    深蓝三档（演播室 / 面板底 / 最暗）
--gold:#C8A24A    --gold-dim:#8A6F31                     金：增长、强调、分隔线
--red:#C4262E     （数字下行用 #E8555C）                  红：角标标记、下行数字
--ink:#EEF3FA     --ink-dim:#C3D2E4                       主文 / 次级文字
--safe:96px                                               四边安全边距
```

**三色编码全片不许乱**：金=增长/强调，红=下行，白=主文。观众靠这个扫读。

### 字体

- 标题 / 大字：`SerifSC 700`（宋体系，给播报的分量）
- 正文 / 数据：`SansSC 400 / 700`（黑体系），数字一律 `font-variant-numeric: tabular-nums` 防跳动
- **自带 woff2，禁 `local()` 承担正文/标题**；`font-weight` 只取 woff2 实有档

### 版式（硬规则）

1. **恒定角标**：左上「▌栏目名 + 期号」，全片不动，是唯一允许带压条的元素。
2. **标题块恒压左下 1/3 的金线上**——纯字卡也不例外（这条是 hero 门 must_fix 沉淀）。
3. **数据在右三分位，标题在左下三分位**，两者不抢。
4. **来源脚注**：只在带数据的镜头出现，右下，极轻。
5. 🔴 **压在画面上的组件一律无底框**——见 §3。

## 3. 无底框铁律（本包的立身之本 · 一票否决）

> 数据卡、角标、数据条、字幕**不许带深色底框**。填充 + 边框 + 投影的浮动面板就是 PPT 风格，是 AI 味最直接的来源。

可读性只准由三样承担：

1. **渐变到透明的压暗层**（`.scrim-rd` 右侧 / `.scrim-b` 底部）——纯渐变，**无可见边界**，是调色不是框；
2. **多层 text-shadow 等效描边**——每个文字块自带，不靠背景运气；
3. **字重与留白拉开层级**。

唯一豁免是**角标级信息**（左上台标那种量级），且要在 CSS 里显式写 `/* lint-allow-panel: 理由 */`。

**脱掉底板后的两个手感坑**（实证踩过）：

- 条形轨道要改**亮色**（`rgba(255,255,255,.22)` 级）。背后已经是压暗区，暗色轨道会直接消失。
- 中性灰蓝的条（如 `#8FA8C4`）会和实拍糊在一起，改**近白**（`#E2EBF6`）。

机器门：`tools/kuleshov-lint.py` ④。宪法出处：`CLAUDE.md` 品味宪法「我们拒绝 · 压在画面上的组件底板」。

## 4. 字幕（一票否决）

- **不许带任何标点符号**。句末标点删除，句中停顿换**全角空格**。
- **无底框**，白字 + 多层阴影等效描边，底部居中。
- 戳 1:1 取自 forced-alignment 逐字轴，**禁按字数比例估算**；每条 ≤16 字（不含标点计），**不跨句合并、不跨剪辑点**。
- 实现要点：**切分仍然用标点**（它是断句依据），只在渲染层剥离。参考 `projects/china-h1-2026-econ/scripts/gen_captions.py`（带「标点残留 0」断言）。

机器门：`tools/kuleshov-lint.py` ⑤。

## 5. 节奏与剪辑

- **语速**：快报体，4.2–4.8 字/s（实证片 4.37）。中文 60s ≈ 280–320 字。
- **音色**：男主播配 `Chinese (Mandarin)_Male_Announcer`（ECAPA min 0.858）；女主播配 `Chinese (Mandarin)_Warm_Girl`。⚠️ `_News_Anchor` 名字最像但**实测是女声**，别按名字选。见 `references/minimax-voices.md`。
- **剪辑点全部落在 forced-alignment 的真实字间间隙中点**，compose 里禁手写秒数。实证片 18 个切点无一例外。
- **单镜 2.5–7s**，最长不超过 8s。主播镜可以长一点（给呼吸），数据镜短一点（给密度）。
- **转场词汇 ≤3 种**：`hard_cut`（默认）／`dip_to_navy`（转折字卡入场）／`gold_wipe`（结论卡入场）。不要更多。
- **无 BGM**。联播体的听感建立在"只有播报声 + 干净底噪"上，垫音乐床会立刻把它推向宣传片。这是风格判断，不是省事——记进 ledger 让音频门知道是刻意的。

## 6. 数字动效（实证坑）

- **count-up 时长 ≤0.45s**（13 帧）。更长的话，屏上会有半秒以上是个**尚未到位的数字**——对数据片来说，观众暂停时看到一个不存在的数字就是事实错误。
- count-up **随元素入场即刻起跑**，不要对齐到旁白念出该数字的时刻。屏显数字可以领先旁白，不可以落后。
- **静帧的 Ken Burns 幅度 ≥ scale 1.08 并叠横向次级位移**。纯缩放 1.04 级在 3 秒内的像素位移太小，`measure-render` 会判静，G2 会当成"幻灯片伪装成视频"。这条实证被评委抓过一次。

## 7. 版式模板清单

| 模板 | 一句话规格 |
|---|---|
| 主播镜 | 数字人全屏 + 右侧压暗 + 右三分位数字组 + 左下标题块 |
| 全屏数据面板 | 深蓝渐变底 + 缓移网格 + 垂直居中的标题/大数/图表（这是**镜头本身**，不是浮动卡，允许有背景） |
| 转折字卡 | 左侧衬线大字（一个词高亮金色）+ 右侧有语义的信息块（涨跌对照行 / 表格行母题）。**右半屏不许空** |
| 实拍 + 数据组 | 实拍全屏 + 右侧无边缘压暗 + 无底框数据组 + 左下标题块 |

| 结论卡 | 上部 kicker + 口径行，下部衬线大标压金线，右侧三指标带方向前缀（「已经跑起来 ·」/「还没接上 ·」） |

## 8. 传播

- 首帧海报化：主播 + 两个方向相反的数字，可直接充当封面。
- 三面开钩一致：封面文案 = 首 3 秒画面 = 口播首句。
- 强监管选题（金融/医疗/法律）：只讲口径与机制，**不给投资建议、不推标的、不预测涨跌**；绝对化用语禁绝。
- 所有数据带绝对时效锚（「上半年 / 统计局 X 月 X 日发布」），不用「昨天 / 最近」这类相对词。
