# 风格包模板（复制本目录起新包）

> 一个风格包是完整的可执行 SKU。考片制准入：从被验证的优秀作品拉片蒸馏（不从脑子里写出来）→ 产样片 → 盲评赢基线 → 才转正。未考片的包一律标 `候选`。

## 0. 档案

- 包名 / 状态（候选 | 已考片 | 下架复审）
- 拉片对象（哪些片 / 账号，`/benchmark-breakdown` 报告链接）
- 适用片型
- 考片记录（样片、盲评结果、日期）

## 1. 风格宣言（≤ 5 句硬观点）

这个风格爱什么、恨什么、一眼认出它的特征是什么。

## 2. 开拍提问模板（elicitation）

每种风格问自己的问题才问得到点上（是枝包问"日常物件锚"，快报包问"数据源"）。3–5 问。

## 3. 视觉系统

- 色板（CSS tokens：背景 / 前景 / 强调色，直接给 hex）
- 字体（标题 / 正文 / 数字，中英各一）
- 版式网格与留白规则
- style frame 锚点（有了就放 `anchors/` 并在此引用）

## 4. 节奏与剪辑

- 语速与 TTS 语气
- 剪辑密度目标（cuts/min）、切点规则、转场词汇（≤ 4 种，列全）
- 引用翻译总表的行名 + 覆写参数

## 5. 声部表（多来源混排才填）

每种来源在本风格里的固定叙事角色（如：HTML=信息主轨，图片动效=氛围插图）。

## 5b. 缝合层（多来源混排必填——**准入硬项**）

多源片散架，散在**跨来源那一镜**上：全片唯一一个换了介质的镜头会被观众一眼挑出来，跟谁写的、什么时候写的无关（2026-07-27 A/C 对照实验，4 臂 12+6 张 hero frame，三次出局镜全是全片唯一换 provider 的那张）。

所以本节要写死**一层对每个 provider 无例外生效的物质约定**，三样缺一不可：

1. **共享物质基底** —— 全片一切画面都长在同一种物质上（同一张纸 / 同一块屏 / 同一层胶片）。实拍、图纸、生成图、版式卡，一个都不例外。
   > 只写"统一颗粒"不够。颗粒能盖在任何东西上，基底决定它们是不是同一个世界里的东西。
2. **统一光照体系** —— 光从哪来、有没有景深、有没有镜面高光，全片一致。
   > 实测判词："同一部片不会有一个镜头突然没有光源。"
3. **常驻几何标记** —— 一件位置固定、每镜都在的东西（比例尺 / 套准十字 / 标尺线 / 常驻边框）。它是观众确认"还是这部片"的锚。

另外两条强烈建议：

- **色板绑语义，不只给 hex。** 实测里色值跨会话传得很稳，跨不过去的是"这个颜色只准表示什么"。写成"青只给冷链基础设施、橙只给人的动线"，不要只写色板表。
- **叙事物件跨镜咬合。** 同一件东西在不同镜里以不同视图出现（平面图里的机房 = 透视图里那排冷柜），比任何滤镜都更能把两个镜头绑成一部片。

**自查**：把本包声部表里的 provider 逐个点名，问"这一层约定在它身上怎么落地"。有任何一个 provider 答不上来，缝合层就不成立——它会在成片里变成那张被挑出来的镜头。

背景与完整证据：`docs/style-pack-form-experiment.md`。
