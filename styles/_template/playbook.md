# 风格包模板（复制本目录起新包）

> 一个风格包是完整的可执行 SKU。考片制准入：从被验证的优秀作品拉片蒸馏（不从脑子里写出来）→ 产样片 → 盲评赢基线 → 才转正。未考片的包一律标 `候选`。
> **起新包的第一个问题不是「它长什么样」，而是「它认领哪个理解任务的空位」**（空位表 `styles/routing.md` §7）。认领不了空位、只是换套美术，说明它应该是未来的视觉修饰包，不是一个新的基础叙事包。
> 本文件是**创作方法**；两个配套件不可省：`capability.json`（路由能力卡，见下）+ `contract.json`（机器硬门）。没有能力卡的包路由器看不见它，`route-style.py --check` 直接失败。

## 0. 档案

- 包名 / 状态（候选 | 已考片 | 下架复审）
- **定位一句话**：这个包解决的核心任务是什么（「让观众……」），对应哪个理解任务
- **叙事骨架**：四到五步，如「主张 → 文件证据 → 解释 → 结论」
- **签名动作**：一眼认出它的**行为**，不是它的材质或颜色（反面教材：把案卷的签名写成「纸张和红色」而不是「带观众读证据」）
- **路由条件**，分两栏写（机器版进 `capability.json`）：
  - **硬前提**（不满足就不是本包）：必需素材 / 排斥素材 / 不适用的敏感题材
  - **原生格式**（实证过的那一档，不是门槛）：画幅 + 时长带宽。🔴 **画幅和时长永远不是硬门**（2026-07-27 拍板）——偏离只是要适配，`capability.json` 里必须写清换画幅 / 压短 / 拉长各要改什么
- 拉片对象（哪些片 / 账号，`/benchmark-breakdown` 报告链接）
- 适用片型
- 考片记录（样片、盲评结果、日期）

## 0b. 能力卡（`capability.json`，与本文同时写）

schema `style-capability@1`，字段与语义见 `styles/routing.md` §2。四条纪律：

1. 只能用 `styles/routing-vocab.json` 里的标签，表外标签路由器直接报错——**不许临时造词**；
2. **硬规则**（不满足就不是这个包）和 **`avoid_when` 软扣分**（能做但不该做）分开写。把品味写进硬规则会让包谁都用不了，把硬约束写成偏好会让路由静默出错；
3. 每条硬规则的 `why` 回链本文的具体条款——硬规则是配方前提，不是拍脑袋的门槛；
4. **画幅和时长写进 `native_format`，不许写进 `hard_rules`**（写了路由器直接报错）。三条 `adaptation`（`aspect` / `duration_shorter` / `duration_longer`）缺一条卡就加载失败——路由器把它们原样打给 EP 当施工说明，所以要写「删哪个槽位、改哪块版式、带动哪条合同阈值」这种可执行的话，写「适当调整」等于没写。

写完在 `styles/routing-cases.json` 加至少三条考题（一条该命中、一条素材前提不成立该落兜底、一条该出格式适配），跑 `python3 tools/route-style.py --check` 全绿。**新包不许改掉老片的路由结果**，改掉了就是能力卡边界没划清。

## 1. 风格宣言（≤ 5 句硬观点）

这个风格爱什么、恨什么、一眼认出它的特征是什么。

## 2. 开拍提问模板（elicitation）

每种风格问自己的问题才问得到点上（是枝包问"日常物件锚"，快报包问"数据源"）。3–5 问。

## 3. 视觉系统

- 色板（CSS tokens：背景 / 前景 / 强调色，直接给 hex）
- 字体（标题 / 正文 / 数字，中英各一）
- 版式网格与留白规则
- style frame 锚点（有了就放 `anchors/` 并在此引用）

## 4. 节奏与剪辑

- 语速与 TTS 语气
- 剪辑密度目标（cuts/min）、切点规则、转场词汇（≤ 4 种，列全）
- 引用翻译总表的行名 + 覆写参数

## 5. 声部表（多来源混排才填）

每种来源在本风格里的固定叙事角色（如：HTML=信息主轨，图片动效=氛围插图）。

## 6. 版式 / 镜头模板清单

本包沉淀的可复用模板（榜单卡 / 大数字卡 / 开场刊头……），每个一句话规格。

## 8. Golden 样片

考片通过的样片 + 得分，回归对照的基准。成片归档 `~/kuleshov-archive/golden/<pack>__<project>.mp4`（重媒体不入库），登记进 `styles/golden-set.json`：实测规格（分辨率/时长/响度/真峰）+ **它证明了什么** + 🔴 **`known_defects`**。

已知缺陷不是可选项：Golden 会被 G2 拿去并排对照，它自己带的违规如果不写明，评委会把旧债当标准（实例：pixel-chronicle 的 Golden 字幕带标点且带底框，早于 2026-07-27 两条宪法级拍板）。
