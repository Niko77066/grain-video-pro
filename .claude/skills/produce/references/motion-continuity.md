# 第一部分 · 接缝法

## 1. 矢量律

> **A 怎么出去，决定 B 怎么进来：同轴、同向、速度接上、两边都切在运动中。**

1. **轴**：x 还是 x，y 还是 y，Z 还是 Z。**跨切点不换轴。**
2. **方向**：不许镜像。Z 轴上"方向"= 缩放变化的**符号**——变大＝推进（镜头向前），变小＝拉远（镜头向后）。
   *最常见的违规*：上一镜后退着出去，下一镜从小长大进来（拉远翻成推进）——因为"从小长大"正是元素入场的默认写法。
3. **速度**：入场初速 ≈ 出场末速。做法是**镜像 ease**（出 `power4.in` + 入 `power4.out`，同距离同时长），
   入场侧从名义路径的 ≥50% 处接手。
4. **相位**：切点落在**两边都还在动**的时刻。切之前先停稳、或切之后从静止起步，都是死拍。

## 2. 全片主方向（current）与保留矢量

每条片选**一个**主方向，所有普通接缝都用它。其它矢量是**保留位**，用掉一个就等于说了句话：

| 矢量 | 含义 |
|---|---|
| 主方向（如左） | "下一拍" —— 中性的推进 |
| 向上 | 升华：结论或揭示，高于前面所有内容 |
| Z 推进（zoom-through） | 往同一个念头的更深处走 |
| Z 后退（inverse zoom） | **到达**：更大的东西落地了 |
| 炸开（scale-burst） | 离开一个世界：某个面从镜头旁擦过去 |

- **连续两个接缝反向 = 错误**，观众读作乒乓球，不是节奏。
- 换方向必须有**可见的因**（一次点击、一次撞击、一次弹跳）或者落在章节边界上。

**本仓落地**：主方向不硬性规定为"左"（官方 house 默认是左）。每片在 storyboard 阶段选一个，写进
`film.json.edit`；风格包可以给默认值。保留矢量花在哪一镜，进 `ledger.decisions`。

## 3. 承接物（carrier）与因果运动

**眼睛跟的是物体，不是抽象概念。** 最强的接缝把一个具体的东西**以匹配的位置和速度**递过切点：
一个正在飞的光标、一个缩进下一版式的容器、一个飞进自己槽位的标记、瀑布切里的那组词。
没有天然承接物时，让本镜主角承担（部分位移 + 提前淡出 + 下一镜半空接手）。

**永远不要用 crossfade** —— 它一个承接物都没有，中点还会变暗。

**因果运动**：每个动作都要看得出是被上一个动作发动的——点击 → 压缩 → 回弹 → 飞行 → 撞击 → 反冲 → 揭示。

- 效果**起在肇因的同一帧**，不是"稍后一点"。
- 反应按隐含质量分级：大元素回弹慢，小元素干脆利落。
- 一次外力才是换方向的许可证；没有肇因的翻转就是乒乓球。

## 4. 接缝目录（五种，参数级）

| # | 技法 | 用在哪 | 轴 | 位移/缩放 | 峰值 blur | ease | 总时长 |
|---|---|---|---|---|---|---|---|
| 1 | **Cut the Curve** | **所有 scene 边界的默认解** | X / Y | ±12% 画幅（1920 ≈ 230px） | 8–10px 可选 | `power4.in` / `power4.out` | ≈0.6s |
| 2 | Zoom-Through（推进） | 同场内文字替换 | Z，变大 | 1→1.2，接 0.75→1 | 文字 10px | `power3.in` / `expo.out` | ≈0.4s |
| 3 | Inverse Zoom（后退） | **到达/落地拍**，不是普通边界 | Z，变小 | 1→0.8，接 1.25→1 | 文字 10px | `power3.in` / `expo.out` | ≈0.7s（出 3 / 入 7） |
| 4 | Waterfall Cut | 大字换大字的逐词接缝 | X，逐词 | ±230px | 无 | `power4.in` / `power4.out` | 出 0.34 / 入 0.3 |
| 5 | Rack-Focus Blur-Cut | **唯一一个"要被看见"的切**，偶发 | 任意 | 轻微 scale 1.06 | 峰值 8–12px（≤16–18） | `power2.in` / `power2.out` | 看拍点 |

**blur 尺度规则**（所有 Z 变体通用）：文字级主体 **10px**（20px 会把字形糊成故障感）；
全屏面（窗口、卡、截图）**18–20px**（大面上轻 blur 读作渲染打嗝）。切点两侧同值。**blur 加在 wrapper，不加在子元素。**

### 4.1 Cut the Curve —— 默认边界的三个要点

- **部分位移**：只走 ~12% 画幅，**绝不整屏移出移入**。
- **镜像 ease**：出 `power4.in` + 入 `power4.out`，同距离同时长——它俩是同一条 `power4.inOut` 的两半，
  所以切点处速度精确相接。**任何一侧用 `.inOut` 都是错的。**
- **淡出提前（fade trick）**：出场的透明度在位移进行到 25–30% 时就走完（淡出 0.18–0.3s vs 位移 0.3–0.34s）；
  入场在 0.35 透明度处半路点火。**最后一个淡出元素要正好死在切点上**——中间空一帧没东西动就是死气。

### 4.2 / 4.3 Z 轴两种的符号纪律

**"同轴"在 Z 上不够，缩放变化率的符号必须一致。** 这条**同时约束下一镜自己的入场动画**（切点后 ~0.5s 内）：
下一镜要么以**已经排好的完整画面**到场，要么把自己的入场写成同符号。
最常见的两个禁忌组合：后退出场 → 从小长大入场；推进出场 → 超大回收入场。

Zoom-through 的出场透明度**必须是独立的线性 tween**——`power3.in` 会把透明度按住太久，
两段文字会同时可见（zoom-through 的铁律是**任何时刻只有一段文字**）。

### 4.4 Waterfall Cut 的参数

逐词版的 cut-the-curve，文字接文字最强的解。出场词按阅读顺序 +0.022s 错峰剥离，入场词
0.05s 起、每词 ×0.84 收缩间隔（越来越快的浪），入场初始透明度 0.35（0→1 会"啪"地弹出来）。
**构建时就把所有词预设成 `x:+230, opacity:0`** —— 只靠 `immediateRender:false` 会让未开始的词以静止姿态可见。

### 4.5 Rack-Focus 的使用配额

只在叙事拍点上放，**≤ 每 8 秒一次**，绝不在字幕中间或一个 hold 里放。切在 blur 峰值（≥6px），
上升途中切会被看见。出场保持**完全不透明**直到切点（靠 blur 藏切，不提前淡出）。
不许在同一个元素的同一条 tween 里同时动 blur 和 opacity（headless 合成 bug）；不许直接 blur `<video>`（套 wrapper）。

> **与 `hyperframes-recipes.md` F16 的关系**：F16-A/B/C 是这套东西的粗版。**接缝参数以本节为准**，
> F16 只保留"背景连续硬切"那条它独有的（同源背景视频对齐 `data-media-start`）。

## 5. 场内技法（不是接缝，别混用规则）

### 5.1 瀑布入场（arrival）

词/元素从下方依次冲进来，每个都在前一个停稳之前起步，越来越快的浪最后收成排好的版式。
用在标题卡、章节开场、清单引入。**和 §4.4 的瀑布切是两回事**：

| | 瀑布入场（到达） | 瀑布切（接缝） |
|---|---|---|
| 透明度 | **二值 0→1，用 `tl.set`，绝不淡入** | 半路 0.35 点火，淡入本身就是速度戏法 |
| 默认轴 | Y，从下方 | X，顺着主方向 |
| 出场侧 | 没有 | 有，镜像 `power4.in` |

- **重叠，不是排队**：下一个在前一个停稳前后 ±2 帧起步，间隔**越来越小**，最后一个"啪"地到位。
- **速度按重量分档**：

| 参数 | 锚点/重元素 | 普通词 | 轻元素/标点 |
|---|---|---|---|
| Y 位移 | 60–80px | 40–50px | 30–48px |
| 时长 | 0.16–0.20s | 0.13–0.16s | 0.10–0.13s |
| 重叠 | 0–2 帧间隔 | 重叠 1 帧 | 重叠 1–2 帧 |

- ease 用 `power4.out`（要更脆用 `expo.out`），入场**绝不用 `.inOut`**；一次级联一个方向。
- 想延长高潮：把**最后一个词**拆成碎片，碎片走更远。

### 5.2 Nudge 三段位移（组位移）

把一组已经排好的内容（词行、卡堆、清单）挪开腾地方。**没有任何内置 ease 能做出这个感觉**——
`power4.inOut` 会"啪"地砸停。必须在同一个属性上串三段：

| 段 | ease | 距离占比 | 时间占比 | 手感 |
|---|---|---|---|---|
| 1 起步 | `power3.in` | ~10% | ~20% | 几乎没动，但运动被注册到了 |
| 2 爆发 | `none`（线性） | ~65% | ~18% | ~2× 平均速度，有目的性 |
| 3 收尾 | `power4.out` | ~25% | ~62% | 衰减着爬到静止，砸停感就是这段杀掉的 |

- **收尾段的时间 ≥ 3× 起步段**。还是砸停就延长收尾的**时间**（不是距离），或换 `power5.out`。
- 第二段必须保持线性——加了 ease 就没有爆发对比了。
- **新内容在第二段里露出**——爆发段掩盖它的出现。

# 第二部分 · 表演法（scene 在进出场之间靠什么活着）

## 6. 禁止 idle wobble

**呼吸、漂浮、缓慢缩放、光晕脉冲这类空转正弦循环，一律不算持续运动**——它们读作"这个视频在等"。
一个 scene 进场完了还剩好几秒，那是**排期出了 bug，加内容，不是加晃动**。
进场与出场之间的每一段，都必须由下面五条路线之一拥有（在 storyboard 里写明是哪条）：

| 路线 | 是什么 |
|---|---|
| **分批揭示** | 内容先扣住，跟着旁白拍点逐块兑现——画面持续在增加信息（≥2 个内容组时的默认解） |
| **有意图的镜头** | 一条画好的 scale+pan 路径：先建立全景 → 行进 → 落到主体上 |
| **界面自己活着** | 产品随时间发生行为：进度推进、高亮换位、数字跳动 |
| **动作序列** | 元素演一段：卡片归入堆栈、条目被拖动、结果被拼装出来 |
| **光标引导** | 超大光标把眼睛带到触发点，它的点击引燃下一拍（§8，本仓片型少用） |

**验收测试：在任意一秒暂停，必须有一件有意义的事正在半空中**——某个揭示正在落地、镜头正在行进、
界面正在做旁白说的那件事。

> **与本仓已有条款的关系**：这条是品味宪法「无意图的运镜」「通常每 8–10 秒发生一次有意义的视觉变化」
> 的施工版；它的机器面是风格包 `contract.json` 的 `render.static_hold_ratio_max`（由
> `tools/measure-render.py` 从终渲反测）。本节讲的是**怎么在 compose 阶段就不欠这笔债**，
> 而不是等终渲被静态持有比例判出来再返工。

## 7. 高潮前的静止 + 时长口径

- **高潮前留 0.3–0.75s 的静止**——动作和它的结果之间那个"戏剧性的逗号"。直接从动作跳到结果，这一下就丢了。
- 单个元素入场 ≤ ~800ms；要更长的铺陈就用**多元素错峰**，不是把一个元素拉慢。
- 出场 ≈ 入场的 75%。**例外**：cut-the-curve 反过来（入场 ≈ 出场的 127%）。
- 总错峰 ≤ 500ms；8 个以上元素时压缩单项延迟，或只给前几个错峰。
- **禁用 ease**：`bounce.out` / `elastic.out`。入场过冲 `back.out(1.4–1.7)` 可以。
- 同类元素共享一套 ease + 时长意图，**不要每个元素一个独门参数**。

## 8. 光标技法（适用边界）

**本仓主力片型（知识科普、新闻调查）默认不用。** 这是产品发布片的房规，前提是画面里真有一个 UI 在被操作；
在信息图/案卷卡上加光标就是"为了动而动"，模板味专项会打。只有当某一镜的叙事动作**就是**"有人在操作这个界面"
时才用，用了写进 `ledger.decisions`。

真要用时，硬规则与可抄代码在 `hyperframes-recipes.md` **F04**（物理进出场禁淡入淡出、尖端命中、
1:2 点击比、click 同帧引燃、不拥有的时段漂到一边）。跨镜交接时光标是最好的承接物（§3）。

# 第三部分 · 渲染正确性

## 9. 不透明舞台底（白闪守卫）

接缝会开出一个"两个 wrapper 透明度之和 < 1"的窗口（cut-the-curve 的半路切、zoom-through 的 0.15 地板、
crossfade 的功率曲线凹陷）。**这个窗口里，wrapper 背后是什么就露什么**——如果 `index.html` 的 `#root`
没有不透明背景，渲染器会把这段合成到它默认的**白**页面上 → **每个接缝一次白闪**，深色片上尤其刺眼。

```css
#root { background: var(--canvas-deep, var(--canvas, #000)); }   /* 组装 index.html 时必须painted */
```

另外两条同源的坑：

- **两个重叠的 wrapper 不许在同一个 track**（同轨重叠在 composition lint 里是非法的）。手写 master 时间线时
  自己保证 track 交替，序号高的合成在上。
- **clip 门控坑**（"零重叠"失败的常见原因）：一个 clip 的 `data-start` 早于它的入场 tween，
  它会以**初始透明度**直接亮相。必须 `autoAlpha: 0` 起手 **且** `data-start` = 切点时刻，不许更早。
