# 引擎知识包 · 视觉出厂自查（版式/画面反模式 linter）

> 何时读我：storyboard 自查、compose 自查、**⑨ review 出厂前必过**。
> 定位：脚本层有 `narration-voice` linter、生成型 b-roll 层有 `clip-qa.py` 死尾判据、技术层有 `hyperframes check`——本文件补上**视觉/版式层**的可执行自查，让出厂前 **agent 自己发现问题、自己指出**，不靠用户逐条挑。
> 由来：`openai-78m-logs` 的 daily-brief v1「全军覆没」尸检（2026-07-17，用户反馈）+ 品味宪法 + 竖屏官号经验。**每条都是踩过的坑。**

## 怎么用（可执行，不是建议）

抽帧过清单：`npx hyperframes snapshot --at <各镜中点>` 出 contact sheet（或成片 review 帧），**逐镜逐项**过下面硬查项。**任一硬查项命中 = fail，必改再出厂**，结论 + 命中项 + 证据帧写 `ledger.gates`。这是 ⑨ review 的一道门。

**先跑自动前置门**：`python3 tools/kuleshov-lint.py projects/<片名>`——把能脚本化的铁律固化成会开火的门（① woff2 禁 local ② 时效词 ③ docsrc 脚注压边框启发式 ④ **组件底板/PPT 味** ⑤ **字幕标点** ⑥ **GSAP 供给/禁 CDN** ⑦ **字幕外挂/禁烧进画面**）；error 不清零禁进人工抽帧。**④⑤ 是 2026-07-27 用户拍板的宪法级项，见 CLAUDE.md 品味宪法「我们拒绝」。**背景见 `docs/postmortem-hf-breach.md`。脚本查不了的（渲染后的像素级重合、音画同步听感）仍靠下面抽帧逐项过。

## 硬查项（一票否决 · daily-brief 尸检清单）

1. **竖屏视觉重心**：内容**居中、填满画面中部**了吗？有没有「上堆下空」（内容挤上方、下半屏大片留白）？→ 竖屏用户视线在中央，上堆下空 = 废镜。
2. **信息层级**：单屏信息元素 ≤ 2 个？有没有「左上 kicker + 左下 src 小字」那套**双角标**（PPT 味的直接来源）？出处并进画面或压到极轻，不抢视线。
3. **文件实证**：讲到**具体文件 / 法规 / 数据**时，画面有没有「读文件」（真截图 / 高保真复现 + 浏览器 chrome + 同步高亮）或数字 callout 压在文件图上？→ **提文件却用纯版式摆字 = fail**（参 samsung `s03-consent-read.html`）。
4. **禁死尾 / 冻结**：烘焙 clip（拼贴 / Seedance）尾段有没有 > 0.8s 近静止（`select='gte(t,dur-1.5)',signalstats` 的 YDIF < 1）？→ 冻结帧补时长是宪法零容忍。版式静态卡属 `typography_led` 本征，不算。
5. **幻灯片化**：连续同版式 / 同景别 ≤ 2 镜？静态类（纯版式 / 图片动效）连续 ≤ 2？每 8–10s 至少一次视觉变化？
6. **模板味**（对齐 D8）：换个选题 / 产品名 / 品牌名，这版画面还成立吗？**成立 = 没做够**。
7. **三面开钩一致**：封面文案 / 首 3 秒画面 / 口播首句 = 同一个承诺？
8. **质感缝合**：混排（拼贴 + 版式 + 文件）靠统一颗粒 / keyline / 点色缝成一家了吗，还是割裂成几段？
9. **文字不拆词**：大字标题有没有把词拆到两行（如「消/失」「匿/名」「办/法」）？→ nowrap 或缩字号。

## 硬查项 · 第二批（英阿片 v3–v6 五轮用户返工沉淀，2026-07-19）

10. **素材重复（零容忍）**：同一实拍素材全片出现 >1 次即 fail——构建期断言 `Counter(broll srcs) 无 >1`，出厂抽帧再人工复核"既视感"。宁可单段拉到 5s，不许复用画面。
11. **时代/地点错位**：叙事段的实拍素材与所述年代/地点冲突（1806 段出现汽车街景、"墨西哥城"配布宜诺斯艾利斯地标）= fail。逐叙事段问一句：**这画面放在这句旁白下，历史/地理上成立吗？**
12. **暗尾黑闪**：素材挂载窗触到源片末尾淡出段（观感=莫名黑屏）= fail。构建期 `media_start+dur ≤ 源长−0.8s`；轨道相邻 clip 断言无缝隙无重叠。
13. **音画同步抽查（协议化 · 关键观感痛点 · 评委 D5/D6 必查一票否决）**：全片均布 ≥6 个句首词，按 timeline 戳切 1.2s 音频独立转写——词不在切片开头 = 对齐层 fail（见 forced-alignment.md）。**字幕/通屏文字、以及版式卡/叠层大字的出现·消失，与口播听感差 >0.2s 即打回**——字幕与 TTS 不同步是最直接毁观感的痛点，`/video-score` 评委必须及时抓、扣到 D5 音画协调 ≤2。派生动作：每个文字元素的入场 `data-start` 对齐其内容词的 timeline 戳（禁手写估算秒；卡片按句首戳、通屏字幕按 forced-align 词戳）。
14. **时效词出厂复核（新增门）**：终渲染前 grep 旁白全文的相对时间词（昨天/今天/上周/上礼拜/刚刚/本周/明天），逐个对照 research 里的**绝对日期**与**预计发布日**核算是否仍准确——制作周期一长，"昨天凌晨"就是硬伤（英阿片 v6 实改）。改词=整条音轨重生成+对齐全链重跑，别抱侥幸。
15. **烘焙镜头拍点**：组装/动画类镜头的完成拍点（payoff 帧）是否落在对应文案上（尾对齐规则，seedance.md）？空纸场/空景撞关键叙事句 = fail。
16. **元素压容器边框（荆华第二片 v3 实改）**：抽帧看**文字/脚注/角标有没有压在卡片内框线、边框、色块边缘上**（案卷卡「来源」脚注压 docbody 内框线是活例——`hyperframes check` 的包围盒重叠**查不出**，因为边框是 CSS border 不是元素）。逐张版式卡问：每个文字块与它所在容器的边框、以及相邻元素，有没有 ≤8px 的贴边/骑线？骑线 = fail。`kuleshov-lint.py` 对 docsrc 这类结构做启发式前置断言，其余靠抽帧目检。

17. **组件底板 / PPT 味（新增门 · 2026-07-27 用户拍板 · 宪法级 · 一票否决）**：压在画面上的**数据卡 / 角标 / 数据条 / 字幕**有没有深色底框？**填充 + 边框 + 投影的浮动面板 = PPT 风格 = AI 味的直接来源，命中即 fail。** 可读性只准由三样承担：① **渐变到透明的压暗层**（`linear-gradient(... rgba(x,x,x,0))`，无可见边界，不构成框）；② **多层 text-shadow 等效描边**；③ 字重与留白拉开层级。唯一豁免是**角标级信息**（左上台标那种量级），且必须在 CSS 里显式写 `/* lint-allow-panel: 理由 */`。附带手感提示：脱掉底板后条形轨道要改**亮色**（`rgba(255,255,255,.22)` 级）——背后已是压暗区，暗轨会消失；灰蓝色条容易和实拍糊在一起，改近白。机器门：`tools/kuleshov-lint.py` ④，实证片 `china-h1-2026-econ`（去底框后 G2 的 D4 版式 3.5 → 4.5）。

18. **字幕：外挂不烧 + 不带标点（宪法级 · 一票否决）**：compose 里还有字幕层吗？→ 交付必须是 **MP4 + 外挂 VTT 两件**，不设烧录变体；字幕**不带任何标点**（句末删、句中换全角空格，切分仍用标点、只在输出层剥离）。两条都由 `tools/make-vtt.py` 一次满足。机器门：`kuleshov-lint.py` ⑤⑦（存量 review/delivered 只 warn，重做即须改）。细则 `compose-contract.md` §6。

19. **字幕是叠加层，不是保留带（2026-07-28 从官方 `captions-overlay` 挖矿）**：构图有没有为了"给字幕腾地方"
    整体上移、在下方留出一条死带？→ **构图必须按真中心排**（横屏 y=540、竖屏 y=960）。**居中在 0.42×H
    再留一条空带，那是 bug 不是解法**；内容可以一直铺到画面底部，满幅主体、背景、色带都欢迎。
    字幕是**合成在整片之上的一层**，不是从版式里挖走的一块。
    唯一的软性礼让：**别把关键小字**（出处行、法规名、副标）正好停在底部字幕带那 ~80px 的中央跨度里——
    叠上去会互相打架；大图、卡片、氛围内容压在字幕下面完全没问题，字幕皮肤本来就是设计成能压着内容读的。
    **没有机器 keep-out 门**，这条靠抽帧目检"字幕压内容还读不读得动"。
    ⚠️ 官方那套 `drop / rail / embed` 三分模型是给**真人出镜片**的（embed = 把一个大词合成到人物身后，
    靠抠像遮挡）——**本仓无真人主体，embed 那一层不适用**。可用的是它的稀缺性原则：**大字强调是稀缺的
    高潮**（每拍 ≤1，相邻不共存，间隔 ≥1 拍），日常内容一律走常规字幕行 + 行内高亮，别把每句都升级成大字卡。

## 五维自评（各 ≥ 4 才出厂，记 ledger）

版式重心 / 层级克制 / 实证充分 / 动静得当(无死尾) / 缝合统一。低于线必改。

## 与评分卡（评委）的挂钩

本清单是 9 维评分卡的**画面侧展开**——打分时对应维度直接引用本清单锚点：
- 硬查 1、2、9、16、17、18 → **D6 字幕与版式**（17 组件底板同时压 **D4 版式**）；3 → **D2 信息准确 / D5 音画协调**（实证）；**13 → D5 音画协调 / D6 字幕与版式（字幕·文字与 TTS 同步，关键观感痛点，评委必查）**；4、5 → **D4 节奏**；6 → **D8 创意**；7 → **D3 开头**；8、12、14、15 → **D7 完成度**。
- 命中任一硬查项，对应维度**扣到 ≤ 2**（**17 / 18 命中直接 fail，不给解释豁免**），并在 `/video-triage` 记一笔归因到环节（style_pack / storyboard / compose）。
