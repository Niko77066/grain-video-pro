# Brief · 城市里的野生动物 EP01：浣熊

## 选题

**系列**：城市里的野生动物·它们怎么活下来的（每期一种成功适应大城市的野生动物，用真实案例 + 生态学讲清它们的食物 / 路线 / 繁殖如何在钢筋水泥里找到生存缝隙）。

**首集主角**：浣熊（raccoon, *Procyon lotor*）。选它做 EP01 的理由：城市适应的教科书案例，三条生态线（食物 / 路线 / 繁殖）在城市语境里都干净且可视化；且有**多伦多市政 vs 浣熊「防浣熊垃圾桶」军备竞赛**这个既真实、又反差、又有网感的强案例做钩子。

## 受众 & 平台

- 平台：小红书 + 抖音（横屏 16:9 知识科普赛道）
- 受众：对城市生态 / 动物行为好奇的泛知识人群；期望"涨知识 + 有反差 + 会转发"。

## 片型 & 承诺

- 片型：`faceless_explainer`（知识讲解）
- 风格包：`pixel-chronicle`（像素纪事·横屏，MG 主导 + 实拍证据的 hybrid）
- 交付承诺：`hybrid`，横屏 16:9
- 时长目标（非硬锁）：~180s（3 分钟）。pixel-chronicle 实测语速 ~300 字/分 → 文案预算 ~820–880 字。最终以 `audio.timeline` 真实时间戳定长，宁短不水。

## 内容引擎（本集骨架）

反差钩子 → 三章递进（食物 / 路线 / 繁殖）→ 情感落地，对齐 pixel-chronicle §7 槽位模板（功能不变、内容置换）：

1. **钩子（反差连击）**：多伦多花百万加元设计"防浣熊"垃圾桶，浣熊还是破解了；城市浣熊比乡下同类更会解锁——城市在"选择"更聪明的浣熊。
2. **章一·食物**：从溪流摸食的机会主义者，到城市里的"人类食物残渣专家"——垃圾、堆肥、宠物粮、果树。城市食物密度远高于野外。
3. **章二·路线**：夜行 + 立体路网——下水道、电线、屋顶、绿化带走廊；避开人类活动高峰的时间生态位。
4. **章三·繁殖**：烟囱 / 阁楼 / 桥洞替代树洞；城市种群密度更高、幼崽存活率更高、寿命反而更短的权衡。
5. **落地金句**：城市不是浣熊的敌人，是它们抢先占住的新生态位——钢筋水泥里，缝隙就是家。

> 三章 = 用户点名的"食物 / 路线 / 繁殖"三条线，逐条对应"钢筋水泥里的生存缝隙"。
