# brief · 《经济半年报》4.7% 背后的两组数字

## 选题

2026 年中国经济半年报（国家统计局 2026-07-15 发布）。片子不做「成绩单朗读」，做**一次结构解读**：同一份半年报里存在两组方向相反的数字，追问 4.7% 是谁扛起来的。

## 用户诉求（原话拆解）

> 「做一个视频，关于财经主题，希望像 CCTV 新闻联播那种感觉，有数字人播报＋实拍素材＋实拍图片＋HTML 演示」

拆成可执行承诺：

| 诉求 | 落法 |
|---|---|
| 财经主题 | 宏观经济半年报，官方统计口径，事实全部回链 research |
| 新闻联播「那种感觉」 | **形式**上对齐：正襟主播、蓝金演播室、红金标题条、庄重播报腔、数据大屏包装、左下角栏目角标。**内容**上不做宣传腔——taste 宪法要求 But/Therefore 与事实回链，做「联播的形，财经解读的骨」 |
| 数字人播报 | HeyGen Avatar 4，全片 3 个主播镜（开场 / 转折 / 收尾），形象锚点按 16:9 半身构图生成 |
| 实拍素材（视频） | Pexels / 档案实拍：港口集装箱、生产线、城市航拍、商圈人流、住宅工地 |
| 实拍图片 | 真实照片走 image_motion（推轨 / 视差），不做 AI 插画 |
| HTML 演示 | HyperFrames 数据大屏：GDP 柱状与目标带、投资/地产负增长条、外贸双曲线、新动能产量条 |

## 片型与承诺

- **片型**：`anchor_news_recap`（数字人主播版资讯速览）。M0 主线片型为 faceless_*，本片带主播属**片型扩展**——记 `ledger.decisions`，不当成已验证片型。
- **风格包**：生产期跑在 `whiteboard-generalist`（兜底包）。理由：联播质感既非 pixel-chronicle 的像素科普，也非 case-file 的竖屏案卷；诉求为「实拍＋数字人＋HTML」混合，正是兜底包 §1 空白链路的适用面。
  > **出厂后改挂 `anchor-desk`**（2026-07-27，`ledger.decisions` d34）：用户认可成片效果后，把本片蒸馏成了独立的新闻播报风格包 `styles/anchor-desk/`，本片即该包的**实证片与参考实现**，合同阈值全部按本片实测标定。上面这条原始决策保留不动——本片确实是在兜底包上做出来的，新包是事后提炼的。
- **画幅**：16:9 横屏（联播是横屏栏目）。
- **时长目标**：~80s（非硬锁，最终由音频定长）。
- **预算上限**：用户未设 → `cap_usd: null`，只记账不熔断。
- **受众**：关心宏观数据但不读统计公报的普通观众；能看懂「投资在缩、外贸在涨」这种结构话。

## 视觉手柄（`meta.style_notes.visual_handle`）

**「联播蓝金数据屏」**：#0A1E3C→#123A6B 深蓝渐变底 + #C8A24A 金色分隔线 + #C4262E 红色强调块；标题永远压在左下 1/3 的金线上；每个数据出场都带一次「数字滚动到位 + 金线扫过」的重复动作；主播镜与数据屏共用同一蓝金调色，实拍素材统一套冷蓝 LUT 缝进同一世界。

## 边界

- 不给任何投资建议、标的推荐、涨跌预测；只复述官方口径与结构变化。
- 不做写实真人重演（风格包唯一硬不兼容项）；数字人是栏目主播人设，不冒充任何真实人物、不使用任何真实主播的形象或姓名。
- 所有数据带「2026 年上半年 / 国家统计局 2026-07-15」时效戳，防时效词漂移。
