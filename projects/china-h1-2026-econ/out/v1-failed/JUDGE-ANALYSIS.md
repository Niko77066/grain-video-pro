## 0. 关于这个 mp4 的诚实交代

`final-v1.mp4` 是**重建版，不是当初那个字节相同的文件**。

原始 v1 成片在回炉重渲前被我 `rm -f` 覆盖了，`~/kuleshov-archive` 的副本也被第二次 rsync 盖掉——**我把它弄丢了，这是操作失误**。所以这份是用 v1 的 composition 重新渲的：

- **画面应当一致**：渲染是确定性的（Docker 固定镜像、无 `Math.random`/`Date.now`、无渲染期网络请求），composition 输入只回滚了 `ledger.decisions` d026 记录的那三处改动的**逆操作**（见 §3），素材文件、音轨、字体、时间轴全部未动。
- **音频链路不同**：原始 v1 的响度处理走了「`loudnorm TP=-1` → 真峰越线 → `alimiter` → 再 `loudnorm TP=-2`」三步弯路；这份只走一次干净的 `loudnorm I=-14 TP=-2`。听感上应该更规整一点点，不影响评委看的任何东西（评委只拿静帧，本来就没听）。
- **一致性验证**：见文末 §6——用 `measure-render.py` 复测，看能不能复现出评委抓到的那个数字。

`compose-v1/index.html` 与交付版 `compose/index.html` 的差异是 **32 行**（`diff` 计数），全部落在那三处。

## 1. 评审机制（先说清楚判词是怎么来的）

- 评委是**隔离 subagent**：与创作者物理隔离，只拿到 contact sheet（整点 + 半步错位）、18 张逐镜中点帧、工艺下限参照 sheet、`l0-report.json` 机器实测、`manifest.json` 镜头事实（**零创作理由**——不给 brief、不给剧本、不给决策日志）。
- **判词由规则派生，不采信模型自报**。`tools/judge/judge.py` 的 `VERDICT_RULE`：

  > `overall < 3.5` **或** 命中任一反模式 → **fail**

  模型自己写的 `verdict` 存进 `verdict_model` 只作校准语料。**两轮评委都自报 pass，两轮都被规则改判 fail。**
- 引用纪律：每个维度的 note 必须带 `sNN` 或 `M:SS`，否则整报作废。两轮 `citations_valid` 都是 `true`。

均分 3.7 高于 3.5 线，但**命中 1 条反模式**，规则判 fail。

### 2.1 反模式（唯一一条）

> **s06_housing_photo**：manifest 承诺「楼体照片缓推特写」(image_motion)，但 `l0-report.json` 实测 `static_hold_ratio=0.755`（2.98s 里 2.25s 判静），命中「幻灯片伪装成视频 / 冻结帧补时长」。

**这条是真的，我认。** 原因是我给 s06 的 Ken Burns 只有 `scale 1.00→1.045`，2.98 秒里总位移约 4.5%——换算到 1920px 宽是每秒约 29px 的边缘位移，画面中心几乎不动。`measure-render.py` 的口径是「相邻采样帧降采样灰度 + boxblur 后平均绝对差低于阈值、连续 ≥0.8s」，这种慢推在帧差层面就是静止。

值得说的是：**这一条我自己的视觉自查没抓到**。我的自查看的是「静态类连续 ≤2 镜」「有没有冻结帧」这些结构性口径，s06 在 IR 里自报 `static_class=true`，所以机器门（`style.contract.render` 的 mislabeled 检查）也放行了——**自报静态 + 实测静态 = 一致，不算错标**。评委是从另一个角度切进来的：它读的是 manifest 里「缓推特写」这句**意图声明**，拿它去对 `l0-report` 的实测值，发现**承诺的运动没发生**。这是隔离评委的价值所在——它不看我的自报字段，看我的承诺和实测对不对得上。

### 2.2 另外两条扣分（未计反模式，但都有用）

**D1 —— s18 的三条判据是旧数字复读：**

> s18(1:20) 画面右侧三条「判据」(+16.9% / +13.3% / +1.3%) 与 s09 / s11 / s07 已出现过的数字完全重复，作为「下半年要看的」前瞻判据缺少新增信息，判据感弱于叙事口号感。

有道理。结论卡本意是「给出判断依据」，但只是把三个已经出现过的数字再列一遍，读者得不到新信息。

**D5 —— 抓到一帧数字不对：**

> `contact-sheet-offset.jpg` 中对应 s05 时段出现一帧 **−7.1%**，与该镜定格值 / 字幕「百分之五点七」不符，无法判断是计数器过冲动画还是数值错误，存疑未定性。

这是 count-up 的过渡帧。我在渲染前的 snapshot 目检里已经收紧过一次（把 count-up 从「对齐旁白念数字的时刻」改成「随元素入场即刻起跑」），但当时留的 0.7–0.9s 时长仍有约半秒的窗口，屏上是个**尚未到位的数字**。评委的措辞很克制（"存疑未定性"），但对一条财经片来说，**观众暂停时看到一个不存在的数字就是事实错误**——这条不该靠"这是动画"来豁免。

### 2.3 评委给的高分处（作为对照）

- **D2 4.3**：18 镜几乎每张数据卡都带来源脚注，14+ 个具体数字可回链。
- **D8 4.0**：双转折设计 + 全片仅一次推近强调设问，「用具体本期数据支撑论点，换选题不成立，非模板套壳」——模板味测试过了。
- **D6 4.0**：「s12 激光设备可见 BOCHU 真实品牌标识，倾向真实实拍素材而非未缝合 AI 生成，塑料感不明显」。

### 这条是评委的物体误认

那个"半圆"是实拍素材里**集装箱货轮的船首**——正俯拍视角下的圆弧形船头，带系泊缆绳，是真实拍摄内容，不是叠加的装饰图形。

证据帧：`../../evidence/judge-pack/rebuttal-s09-ship-bow.jpg`（s09 左半幅放大）。

**所以我没有按这条回炉。** 为了迎合一次物体误认去改真实素材，是错误的处置。

## 5. 音频门 · 无法执行

隔离评委如实回报：

> `{"unable_to_listen": true, "reason": "Read 工具无法打开该音频：返回 This tool cannot read binary files。文件本身完好存在（984,532 字节，ID3v2.4 + MPEG layer III，96 kbps / 48 kHz / Stereo），但本会话没有任何可用的音频播放或听觉输入能力（Read 仅支持图片/PDF/notebook，无 ASR 或音频感知工具）。因此无法真听，拒绝编造转写与听感。"}`

**它拒绝编造，这是正确行为**，不是失败。音频侧改由机器证据承担：独立 ASR 回转写重合率 0.9935、响度 −14.11 LUFS / −1.34 dBTP、forced-alignment 锚点切片 8/8。

**剩余缺口是人耳听感层**：音色像不像栏目嗓、有无爆音齿音、停顿是否自然、语速压不压得住。这层只能你听。

## 6. 为什么最终没有 delivered

三条依据叠加（`ledger.decisions` d027）：

1. 第 2 轮唯一反模式已被证据反驳；
2. `tools/judge/README.md` 的**「先校准后放权」**协议——本仓没有 `calibrate.py` 的达标记录（Spearman ρ ≥ 0.7 且无系统性放水），**评委尚未获得否决权**，此阶段 fail 的规定处置就是「记 DEBT 停 review，不阻断出片但禁 `delivered`」；
3. SKILL §6 止损：本阶段已修订 1 轮、评审 2 轮，其余扣分点都是 ≤0.5 分的打磨项，不是门级缺陷。

`style.contract.*` **零 error**——本片没有合同违约，`meta.contract_amendments` 全程为空。停在 review 的原因**只有**评委门。
